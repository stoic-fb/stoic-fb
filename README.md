## 👨‍💻 About Me

I'm a **Computer Engineering student and full-stack developer** with a strong interest in backend architecture and reliable systems.

My recent work combines **Go and PostgreSQL**, **Node.js and Express**, **Python and Django**, and **Astro, React, and TypeScript**. I choose the stack around the project's needs, including vanilla JavaScript when a framework would add unnecessary complexity.

I build bilingual English/Persian interfaces, APIs, background workers, monitoring tools, and operational dashboards. I also work on database design, authentication, access control, Linux deployment, and web performance.

I learn by building real products, tracing how their layers interact, and validating changes with builds and focused tests. AI-assisted development is part of my workflow, alongside explicit architecture decisions, review, and verification.

## 🚀 Recent Projects

### [StoDesk](https://github.com/stoic-fb/StoDesk)

A workspace for developers and small teams to manage clients, websites, support requests, and monitoring, with a restricted client portal.

- **Stack:** Node.js, Express, Python, Django, SQL Server, HTML, CSS, and vanilla JavaScript.
- **Focus:** tenant isolation, session authentication, scheduled HTTP/SSL checks, incident history, and live updates through server-sent events.

### BlackEye Telegram Bot · Closed source

A Telegram Business companion that notifies connected account owners about message edits and deletions, with an admin panel for server health and service operations.

- **Stack:** Go, PostgreSQL, Telegram Bot API, JavaScript, HTML, and CSS.
- **Focus:** durable background jobs, retries, bilingual notifications, storage monitoring, and scheduled backups for selected accounts.
- Source code and operational details are not published here.

### [stoic.ir](https://stoic.ir) · [Portfolio source](https://github.com/stoic-fb/myportfolio)

My bilingual English/Persian portfolio, built with static HTML generation and progressive enhancements.

- **Stack:** Astro, React components rendered at build time, TypeScript, Zod, and Cloudflare Pages.
- **Focus:** RTL/LTR layouts, structured JSON validation, localized URLs, technical SEO, responsive images, and minimal client-side JavaScript.
